01처리하는 정보와 목적

로그인Google 로그인으로 전달되는 계정 식별자와 이메일 주소를 사용해 사용자를 구분하고 계정별 자료 접근을 제한합니다. Google에서 기본 프로필 정보를 제공할 수 있으나 리플로우 화면은 계정 식별자와 이메일을 사용합니다.
직접 저장한 자료웹사이트 주소, 캡처 이미지, 업로드 이미지, 제목, 태그, 메모, 프로젝트 이름·설명·구성을 저장해 레퍼런스와 프로젝트 기능을 제공합니다. 자료에 개인정보를 입력하면 그 내용도 함께 저장됩니다.
서비스 운영캡처 작업 상태와 오류를 처리하고, 로그인 세션을 유지합니다. 서버·호스팅 제공자는 접속 및 오류 관련 기술 정보를 처리할 수 있습니다.
기기 설정테마, 앱 설치 상태, 알림 켜기 여부 등은 사용 중인 브라우저에 저장됩니다. OS 알림은 사용자가 허용한 경우 앱이 열려 있을 때만 표시하며 서버 푸시 구독을 만들지 않습니다.

리플로우는 Google 메일 내용이나 Google Drive 파일을 읽기 위한 권한을 요청하지 않습니다. 현재 외부 AI 분석 기능도 연결되어 있지 않습니다.

02보유 기간과 삭제

계정 자료는 이용자가 서비스를 사용하는 동안 보관합니다. 개별 레퍼런스나 프로젝트는 서비스 화면에서 삭제할 수 있습니다. 원본 레퍼런스를 삭제해도 프로젝트에 따로 보관한 스냅샷은 남을 수 있습니다.

로그인 세션 쿠키의 최대 유지 기간은 14일이며, Google 로그인 과정의 임시 인증 쿠키는 최대 10분입니다. 세션은 로그아웃하거나 유효 기간이 끝나면 사용할 수 없게 됩니다.

계정 전체 삭제를 원하면 tnfh23@gmail.com으로 요청해 주세요. 요청을 확인한 뒤 계정과 연결된 데이터·이미지의 삭제를 처리하고 결과를 안내합니다. 현재 자동 탈퇴 기능은 제공하지 않습니다. 법령에 따라 보관해야 하는 정보가 있으면 해당 기간에 한해 별도 보관한 뒤 삭제합니다. 삭제 대상 데이터와 연결된 이미지는 운영 저장소에서 제거합니다. 제공자 백업 사본에는 제공자의 보관 주기가 적용될 수 있습니다.

03외부 서비스 이용

리플로우는 다음 서비스를 사용합니다. 서비스 제공 과정에서 해당 사업자가 필요한 정보를 처리할 수 있습니다.

GoogleGoogle 계정 인증
Supabase계정 인증, PostgreSQL 데이터베이스와 이미지 저장소 운영. 데이터베이스 프로젝트는 서울 지역으로 설정했습니다.
Cloudflare웹사이트 제공, API 실행과 사용자가 요청한 웹페이지 캡처 처리. 네트워크 및 실행 위치는 제공자의 글로벌 인프라 설정에 따릅니다.

사용자가 저장한 외부 웹사이트 주소는 캡처 작업을 수행할 때 해당 사이트에 요청됩니다. 외부 사이트에는 접속 사실이 전달될 수 있습니다. 리플로우는 개인 자료를 광고 판매 목적으로 제공하지 않으며, 법령 또는 이용자의 별도 동의가 있는 경우를 제외하고 독립적인 제3자에게 제공하지 않습니다.

Supabase의 인증·데이터베이스·이미지 저장소는 서울 지역 프로젝트에서 운영됩니다. 다만 사업자의 서비스 운영에 필요한 일부 기술 정보는 해당 지역 밖에서 처리될 수 있습니다. Cloudflare는 별도 지역 제한을 설정하지 않은 글로벌 네트워크에서 요청과 캡처 작업을 처리합니다.

05보호 조치와 기기 설정

서비스는 HTTPS를 사용하고, 공개 앱의 로그인 세션은 브라우저에서 읽을 수 없는 보안 쿠키로 관리합니다. 개인 데이터와 이미지 접근은 계정별 권한으로 제한합니다.

브라우저 알림 권한과 쿠키·사이트 저장 정보는 브라우저 설정에서 차단하거나 삭제할 수 있습니다. 필수 로그인 쿠키를 차단하면 계정 기능을 사용할 수 없습니다. 리플로우의 알림 설정은 사용 중인 기기에만 적용됩니다.
