# REFLOW 시안 검토 기록 — 2026-10-11

아래 초기 기록의 단계: 생성 이미지 콘셉트 검토. 실제 앱 렌더·조작·API·반응형·성능 QA가 아니다. 최종 저장한 다섯 PNG를 view_image로 모두 확인했다. 당시에는 구현 전 검토였다. 이후 사용자 구현 요청으로 승인된 기준에 맞춰 작업했다.

|---|---|---|
| 셸 일관성 | 데스크톱 네 화면에 동일 REFLOW 워드마크·좌측 사이드바·상단 검색·팔레트를 적용. 보드에서는 프로젝트 메뉴가 선택됨 | 실제 셸 크기·해상도 변화·라우트별 활성 상태 |

## 실제 시안의 차이와 구현 전 보완

- 라이브러리 이미지 생성에서 ALONG, STUDIO KIN 예시가 추가됐다. 모두 가상의 생성 예시이며 실제 샘플 목록을 승인한 것은 아니다. 실제 서비스의 샘플 데이터와 자산 선정은 별도다.
- 비교 화면의 전후 프레임은 서로 다른 건축 장면을 포함한다. 콘셉트용 배치 예시로만 사용하며 실제 모션 관찰의 근거로 재사용하지 않는다. 실제 서비스에서는 같은 대상의 관찰 전후 프레임을 저장해야 한다.
- 정적 이미지로 hover·스크롤·드래그·자동 작업 진행·가입/저장을 검증할 수 없다. 인터랙션 맵에 설계한 동작은 구현 단계에서 시험한다.
- 로그인·URL 입력 모달·프리뷰·디자인 방향 결과·빈 상태·실패/한도·Dark·추가 모바일 상태는 구현 전에 같은 디자인 시스템의 상태 설계가 필요하다. 이번 다섯 장으로 전체 앱 상태가 완성됐다고 하지 않는다.
- 시안에서 보이는 CSS 값·태그·메모·사이트 화면은 생성 예시다. 실제 데이터 분석 결과가 아니며 런타임 데이터와 구분한다.

## 생성과 사용한 지침

사용자 skills-hooks frontend-experience, Build Web Apps frontend-app-builder, imagegen. 내장 image_gen.imagegen으로 생성·편집했으며 CLI/API 키 방식은 사용하지 않았다. 전체 생성/편집 요청은 prompts.json에 보관했다. 커스텀 디자인 에이전트·서브에이전트는 사용하지 않았다.

## 구현과 시안 대조 — 2026-10-11

사용자의 구현 승인 후 로컬 앱을 만들었다. 라이브러리·상세·보드·모바일 콘셉트와 실제 렌더를 view_image로 대조했다. IAB 1536×1024, 820×1180, 390×844에서 직접 조작했다. IAB 저장 이미지가 표시 영역에 맞춰 축소되어 Playwright CLI로 원본 크기 1536×1024 렌더를 보조 기록했고, 움직임 감소도 CLI로 에뮬레이션했다.

| 대조점 | 판단·수정 |
|---|---|
| 문구·아이콘 | REFLOW, 새 레퍼런스, 탐색·검색·필터·비교 문구를 유지. 로그인/개인·예시 구분/실제 캡처 편집은 확정 기능에 필요한 추가다. 화살표·chevron·추가 기호를 제거했고 기본 스크롤바 방향 버튼도 숨겼다. |
| 구조·간격 | 208px 사이드바·상단 검색·최근 3개·4열 Masonry·상세 레일/큰 캡처/우측 분석·4섹션 보드 유지. 태블릿 잔여 display:contents 스타일을 제거했다. |
| 타이포 | UI Pretendard, 제목 32px, 컨트롤 14px. 상세의 타이포 값은 실제 CSS 결과로 바꿨으며 시안의 가상 Inter 64px 값을 재사용하지 않았다. |
| 팔레트·컨테이너 | 흰 본문·차가운 회색 사이드바·코발트·단일 경계·열린 이미지 구성 유지. 다크에서도 사진에 테마 색을 씌우지 않았다. |
| 자산·프레이밍 | 시안의 합성 썸네일은 직접 만든 가상 사이트 8개의 실제 캡처로 대체했다. 사진 세부 장면은 독립 생성 자산으로 바뀌었다. Masonry/보드의 cover가 글자를 자르던 문제를 고쳤다. |
| 반응형·입력 | 모바일 하단 탐색·최근 가로 탐색·2열·더보기 유지. 주요 터치 조작 44px, 프리뷰 방향키/Escape·포커스 복원, 크롭 드래그, 보드 드래그·메뉴 이동 확인. 새 프로젝트 생성 시 선택 자료 유지와 빠른 메모 저장을 수정했다. |

빈 앱·프레임워크 오류 화면·관련 콘솔 오류가 없었다. 실제 URL 저장 후 비동기 완료, 외부 example.com 캡처, 메모 검색과 매칭 이유, 편집·크롭·비교·예시 복사·보드 이동·테마/새로고침 유지가 동작했다. API 검사 14개는 데이터 격리·중복·재캡처·업로드·크롭·스냅샷 유지·선택 업데이트·삭제 보존·미연결 AI 안내 등을 통과했다. 빠른 입력 후 이동한 메모도 저장됐다.

실제 데이터·독립 사진·계정/캡처 편집 컨트롤은 의도적 차이다. 셸·타이포·팔레트·이미지 구성의 수정 가능한 주요 어긋남은 처리했다. AI/Google/클라우드·모바일 별도 자동 캡처·실제 iOS/Safari·공개 운영은 검증 완료로 표시하지 않는다. AI 결과 콘셉트 08은 향후 연결 화면 기준이며 실행 결과가 아니다.
