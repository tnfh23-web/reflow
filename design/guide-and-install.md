# 사용법과 앱 설치 — 구현 전 기준

콘셉트: 09-user-guide.png. 기존 흰색 앱 셸·208px 사이드바·Pretendard·코발트 선택색을 유지한다. Rawdoc welcome/guides의 짧은 기능 설명과 직접 기능을 여는 안내를 참고하며 구조나 문구를 복제하지 않는다.

사용법은 저장·관찰과 메모·비교·프로젝트·앱 설치의 다섯 단계 선택 화면이다. 제목 32px, 설명 16px, 단계 14px, 버튼 38px/터치44px. 단계 열 230px, 간격18px, 우측 유연한 패널, 예시 아래 실제 기능 버튼과 단축키·FAQ. 모바일은 단계 가로 스크롤, 예시 세로 배치. 시안 속 설치 아이콘은 사용자 화살표 금지 지시가 우선이므로 창 모양 아이콘으로 교체한다.

인터랙션: 단계 선택/키보드 이전·다음/진행선 변화 → 내용 교체 GSAP 0.24초; 연습 저장 버튼 → 명시된 시뮬레이션 3단계; 구간 선택 → 실제 예시 캡처 변경; 메모 연습 → 화면 내 입력만; 비교 맞춤 → 이미지 프레임 변화; 보드 배치 연습 → 선택 구간 변경; FAQ → 자연 높이 펼침. 연습은 데이터 저장이나 API 호출을 가장하지 않는다. 실제 기능 버튼은 기존 기능에 연결한다.

PWA: 별도 창·홈 화면 아이콘. 설치 이벤트가 있을 때만 브라우저 설치창을 호출하고, 없는 환경은 OS별 안내를 표시한다. 설치 확인 전 완료 상태를 만들지 않는다. 오프라인은 빌드된 앱 셸과 사용법만; 개인 자료·캡처·저장은 서버 연결 필요. API/개인 이미지/업로드는 SW 캐시에서 제외. 새 버전은 작업 도중 강제로 새로고침하지 않는다. 개발 서버는 HMR을 캐시하지 않는다.

모션 감소에서는 등장·단계 전환을 생략하고 기능은 유지한다. 네이티브 스크롤을 사용해 입력·중첩 화면·모바일 터치를 보존한다. 검증은 실제 IAB 입력 후 상태 확인, Playwright로 PWA manifest/서비스 워커·오프라인·정확한 뷰포트 보조 검증. 공개 HTTPS 배포와 실기기 iOS 설치는 별도 범위다.
