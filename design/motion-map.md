## 라이브러리 사용 원칙

GSAP는 이미지 확대·상태 연결·정렬 반응에 사용하고, ScrollTrigger는 캡처 탐색의 섹션 연결과 제한된 등장 효과에 사용한다. 모든 데이터 패널에 같은 fade-up을 반복하지 않는다.

2026-10-11 사용자 추가 요청으로 앱 전체에 Lenis를 적용했다. 페이지와 이미지 뷰어·구간 목록·분석 패널·비교·보드·모달·사용법의 내부 스크롤 루트를 별도로 연결하고 단일 GSAP ticker로 갱신한다. 터치는 브라우저 관성을 유지하며, 입력칸/직접 영역 선택은 제외한다. 키보드와 경로 변경은 남은 관성을 중단하고 움직임 감소에서는 Lenis를 해제한다. 소개 #about의 첫 핀/탭 구성은 사용자 피드백으로 폐기했다. 새 소개는 일반 문서 흐름의 캡처 선택·구간/메모·체험 보드로 구성한다. 세 제목에 SplitText 글자 순차 등장, 본문/이미지/항목/보드에 다시 재생되는 ScrollTrigger 효과를 적용한다. 시안과 모션 명세는 design/intro-brief.md를 따른다. 공통 앱 헤더는 아래 스크롤에 숨고 위 스크롤에 표시하며 소개 재진입은 최상단이다.

Three.js는 이번 핵심 서비스 기능에 필요하지 않아 설계에 추가하지 않았다. 불필요한 RAF·화면 밖 루프를 줄이고 입력을 가로채지 않는다. 자동 관찰은 서버 브라우저의 별도 기능이며 앱의 장식 모션과 구분한다.
