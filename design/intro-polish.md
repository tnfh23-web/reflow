# 앱 설치·등장 시점·마퀴 수정 — 2026-10-11

최신 사용자 요청: 다른 내용은 유지하고 앱 설치 안내를 실제 웹사이트 UI와 같은 화면으로, 참고 영상의 빠른 클릭/전환 리듬으로 변경한다. 모든 등장은 너무 빠르고 시작 시점이 어색하므로 점검한다. 마퀴는 본문 그리드를 벗어나 전체 콘텐츠 폭을 채운다.

앱 안내는 실제 REFLOW 라이브러리/사이드바 위치, 실제 InstallDialog 컴포넌트의 지원 브라우저 상태, 실제 앱 창 모드의 UI를 캡처한 자산으로 구성한다. 지원/standalone 표현 상태를 검증 프로필에서 제어했으며 OS 설치·네이티브 설치창을 녹화한 것은 아니다. 네이티브 확인창을 임의로 만들어 동일하다고 주장하지 않는다. 소개의 재생은 실제 설치를 실행하지 않는다. 6초 주기, 짧은 클릭·0.2~0.35초 전환, 확인 화면 약1.8초 유지, 자동 반복. 새 가상 설치창/회색 블록 UI를 제거한다.

등장은 기본 HTML 가시성을 보존하되 일반 모션이 초기화되면 아래 화면의 요소만 대기 상태로 설정한다. 화면 위12%/아래14%를 제외한 영역에 들어오면 글자/본문/이미지를 순서대로 시작한다. 충분히 화면 밖120px 이상 지나간 뒤에만 다시 준비한다. 글자0.72초/간격0.085초, 본문1.8초, 이미지2초, 항목1.35초/간격0.18초. 뒤로 스크롤에서도 실제 재진입에 맞춰 시작한다. 그래픽 반복은 외부 등장 완료 후 시작해 첫 동작을 놓치지 않게 한다. reduced-motion은 모두 즉시 표시한다.

마퀴 폭은 main의 실제 폭으로 측정하고 본문 max-width/패딩 만큼 바깥으로 확장한다. 데스크톱의 고정 앱 사이드바는 유지하고 모바일은 viewport 양끝까지 채운다. 큰 화면/태블릿/모바일, 가로 넘침0과 호버 중 이동을 확인한다.
