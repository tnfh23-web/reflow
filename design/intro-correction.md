# 소개 수정 — 2026-10-11

최신 사용자 요청이 앞선 체험 설계보다 우선한다. 소개는 서비스의 용도와 기능을 설명하는 읽기 전용 페이지다. 여섯 영역의 분량·현재 큰 이미지와 타이포·두 마퀴를 유지하고 새 기능을 추가하지 않는다. 기존 시안16~19의 구도는 활용하되 모든 조작 UI를 제거한다. 새 시안 생성이나 서비스 기능 재설계는 필요 없는 기존 화면 수정이다.

- 본문 버튼/링크/입력/select/range/checkbox/textarea 없음. 공통 앱 메뉴는 유지.
- 사이트 캡처·메모·비교·보드는 예시 그림. 자동 반복하며 화면 밖/비활성 탭에서는 쉰다. 정지/재생/다시 보기 버튼과 실제 저장 안내 띠는 제거.
- 제목은 즉시 읽을 수 있게 표시. 첫 제목을 투명하게 만들거나 서로 다른 글자 레이어를 교차하지 않는다. SplitText의 펼침은 가시성을 유지하고 최초 뷰포트를 스크롤 실행 조건에 맡기지 않는다.
- 하위 제목은 스플릿 펼침, 본문과 이미지의 느린 등장 유지. 기본 HTML은 항상 보이며 실행 조건 누락 시 빈 페이지가 되지 않도록 구성.
- 사용자가 움직임 감소를 선택하면 모든 자동 반복을 끄고 각 설명 그림을 완성 상태로 보인다.
- 처음 진입/새로고침/반복 진입/샘플 데이터 지연·재배치/반응형에서 빈 첫 화면 없음, 자동 반복 두 주기 이상, 본문 컨트롤0을 검증.

마퀴 최신 피드백: 큰 한글 대신 얇은 코발트 띠/작은 흰색 영문 monospace(17px, 모바일14px). 리플로우 기능에 맞는 문구. 호버/포커스 정지와 모든 조작 UI 없이 계속 흐른다. 앱 설명은 브라우저 틀에서 앱 창 분리/작업 표시 아이콘의 반복 그래픽으로 구성한다.
