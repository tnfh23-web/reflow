# 소개 확장 — 2026-10-11

사용자 요청: https://codepen.io/barthendrix/pen/VYLaayz 의 눌린 글자→펼침→윤곽선 효과, 소개 분량 확장, 중간 마퀴, 적절한 모션 그래픽, 빠르고 잘 안 보이는 등장 효과 개선.

기존 사용법과 서비스 기능은 유지한다. 소개는 여섯 영역(기존 캡처 갤러리, 새 캡처 과정, 기존 구간/메모, 새 비교 체험, 기존 프로젝트 보드, 새 검색/앱 설치)으로 확장한다. 일반 문서 흐름으로 읽고 조작하며 핀이나 스크롤 강제 전환은 추가하지 않는다.

새 시안16~19: 제목 윤곽선 상태, 캡처 과정, 비교, 검색/설치. 기존14/15가 메모와 보드를 규정한다. 시안의 불필요한 sidebar 기호/다른 브랜드 마크는 적용하지 않고 기존 앱 셸을 유지한다. 가상 사이트 이미지/문구 대신 기존 실제 샘플 캡처를 사용한다. 제목/버튼/기능 설명은 네이티브 UI. 새 기능이나 클라우드/AI 연결을 시안에서 추정하지 않는다.

## 시스템과 모션

- Pretendard, 기존 흰색/다크 토큰, 코발트 #3454f4. 큰 제목50px/모바일31px, 설명17/15px, 프레임6px, 버튼44px 이상. 화살표/chevron/더하기 금지.
- SplitText: 글자 yPercent40·scaleY0.5·opacity0에서 y0·scaleY1·opacity1로, 아래를 축으로 펼침. 글자간0.035초, 본 효과0.8초. 히어로는 채운 글자에서 코발트 윤곽선으로 연결하고 제목 모션 다시 보기 버튼 제공. 다른 다섯 제목은 펼쳐진 글자를 유지해 읽기 쉽도록 한다. 폰트/줄바꿈 autoSplit 및 aria-auto, 이탈 시 revert.
- 기존0.45~0.65초/시작top92~93%는 눈에 띄기 전에 끝날 수 있었다. 새 본문1.15초·항목1초/stagger0.16초·이미지1.4초, 시작top80~82%로 변경. 충분히 지나간 뒤 돌아오면 재생한다. 모바일 작은 항목은 같은 입력 정책을 따른다.
- 캡처 과정: 주소 저장·전체 캡처·구간 분리를 모션 그래픽으로 설명. 실제 샘플을 이용한 안내 예시라고 표시. 자동1회 진행·재생 버튼·일시 정지·화면 밖/비활성 탭에서 정지. 실제 서버 캡처나 진행률로 가장하지 않는다.
- 마퀴 두 곳: 흰 배경 코발트 텍스트 / 코발트 배경 흰 텍스트. 반복 트랙, 서로 다른 방향, 일정한 느린 속도. 화면 밖/비활성 탭 정지, hover/focus/멈추기 버튼, 움직임 감소 정적 텍스트.
- 비교: 같은 Hero 캡처를 나란히/겹쳐 보기, 겹침비율 키보드/터치 range, 기준선 체크. 실제 비교 화면에 연결한다.
- 검색/설치: 공개 샘플 제목/기획 태그의 로컬 체험 필터, 실제 상세 연결. PWA 설치 안내 연결. 앱 창 도형은 기존 UI와 캡처를 쓰는 코드 모션 그래픽. 개인 자료 저장·캡처에는 실행 중인 로컬 서버가 필요하다고 표시한다.

새 paid API, 플러그인 설치, 공개 배포, 개인 자료 변경은 요청 범위에 없다.

최종 QA에서 문서 끝의 등장 시작을 clamp로 보정했다. 마지막 CTA는 최대 스크롤에서도 숨지 않는다. 캡처/앱 그래픽의 화면 밖 정지는 각 그래픽의 실제 보이는 영역을 기준으로 한다.
