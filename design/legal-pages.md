# REFLOW 서비스 문서 디자인

2026-10-13. 이용약관·개인정보처리방침도 리플로우에 맞는 디자인을 갖추라는 사용자 요청이다. 기존 문서 내용과 공개 URL을 유지하며, 앱의 시각 체계를 정적 문서 화면에 연결한다.

## 콘셉트와 근거

`legal-reader-concept.png`는 내장 Image Gen으로 만든 데스크톱 읽기 화면 시안이다. 앱과 같은 밝은 사이드바, 코발트 제목 띠, 번호가 있는 목차와 열린 본문을 하나의 문서 화면으로 구성한다. 상단의 겹친 문서는 리플로우의 보관·분류를 코드로 표현하는 단순 도형이며 사진이나 생성 이미지 자산을 실제 UI 배경에 넣지 않는다.

시안의 자동 생성 문장은 문서 내용으로 사용하지 않는다. 현재 두 HTML의 제목·설명·본문·시행일·연락처가 문구 기준이다. 시안의 그라데이션처럼 보이는 표현은 앱의 확정된 단색 `#3454F4`로 구현하고 사이드바는 실제 앱과 같은 208px을 사용한다. 이 차이는 사용자 지시와 기존 디자인 시스템을 보존하기 위한 의도된 조정이다.

## 디자인 시스템

- 배경 흰색 `#FFFFFF`, 사이드바 `#F6F7F9`, 본문 `#191B20`, 보조 글자 `#6B707A`, 경계 `#E5E7EC`, 선택 `#E9EDFF`, 강조 `#3454F4`. 기존 기기 테마를 읽으며 다크는 앱의 `#15171B`·`#1E2127`·`#F3F4F6`을 따른다. 다크 목차 글자는 대비를 위해 `#A0ACFF`를 사용하며 제목 띠는 코발트를 유지한다.
- 제목·본문·컨트롤은 Pretendard. 워드마크 27px/700, 문서 제목 데스크톱 52px·모바일 34px/700, 본문 16px/1.9, 목차 13px, 헤더 13px. 문구를 장식용 영어로 반복하지 않는다.
- 고정 사이드바 208px, 상단 서비스 문서 헤더 76px. 코발트 제목 띠는 카드 테두리 없이 본문 전체 폭을 쓰고 내부 여백 48px. 아래 읽기 영역은 목차 236px와 가용 폭 본문을 최대 1264px 셸 안에 둔다. 섹션은 열린 문서 흐름과 가는 선으로 구분한다.
- 제목 옆에는 겹친 문서 두 장과 기존 작은 사각형 브랜드 마크를 배치한다. SVG는 실제 텍스트와 분리된 간단한 선·사각형만 사용한다. 장식용 화살표와 chevron은 없다.
- 데스크톱 문서 탭은 사이드바의 기존 선택 행을 따른다. 모바일은 상단 브랜드·서비스 복귀와 두 문서 탭, 본문 위 접을 수 있는 목차로 바꾼다. JavaScript가 없으면 목차와 모든 내용이 그대로 보인다.

## 검증 기준

두 문서와 모바일에서 텍스트 가시성·목차 동작·선택 상태·가로 넘침·키보드·테마·움직임 감소를 확인한다. 본문을 접거나 늦은 등장 때문에 숨기지 않는다. 기존 문서 내용 변경0, 기존 문의 메일 변경0을 따로 비교한다. 시안과 실제 스크린샷의 타이포·배경·띠·사이드바·목차·본문 간격을 view_image로 확인한다.

시안의 주요 구성과 기존 앱 시스템을 기준으로 실제 화면을 view_image에서 비교했다. 데스크톱은 IAB의 논리 viewport 1536×1024이며 스크롤바를 제외한 이미지 폭은1520px다. 움직임 감소는 CSS/Lenis 비활성 분기를 검토했고 실기기 OS 설정의 직접 전환은 미검증이다.
