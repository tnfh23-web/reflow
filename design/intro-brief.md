# REFLOW 소개 페이지 — 두 번째 구성

첫 구성의 독립 헤더, 왼쪽 기능 탭·오른쪽 데모, 스크롤 핀은 사용자가 Rawdoc와 너무 비슷하다고 평가했다. 최신 요청에 따라 폐기하고 다음 세 체험 영역을 새 시안으로 만든 뒤 구현한다. 사용법 #guide는 유지한다.

1. 캡처 확인: 상단 제목/설명, 큰 선택 캡처와 세 샘플 선택. 실제 FORM ARCHIVE·FIELD NOTES·PULSE STUDIO 자산을 사용한다.
2. 구간과 메모: 제목을 가로로 배치하고 아래 캡처 선택/개인 메모를 나란히 구성한다. Header·Hero·Projects를 선택하며 메모 입력과 초기화가 가능하다. 실제 저장 안 됨을 표시한다.
3. 프로젝트 체험: 선택한 구간, Hero·콘텐츠 분류 보드. 추가/제거/초기화는 페이지 내 체험 상태만 변경한다. 실제 라이브러리 시작 버튼을 제공한다.

## 시스템

기존 앱 사이드바와 검색 헤더를 소개에서도 공통 사용한다. 소개 아이콘은 circle-i, 활성 상태는 채운 배경이다. 별도 소개 내비게이션과 메뉴 밑줄은 없앤다. 헤더는 아래 스크롤에 숨고 위 스크롤·입력 포커스에 표시된다. 소개에 다시 들어오면 이전 위치 대신 최상단으로 시작한다.

Pretendard, 기존 light/dark 토큰, 흰색/코발트, 6px 프레임. 제목 50px/모바일31px, 설명17/15px. 화살표·chevron·더하기 기호를 넣지 않는다. 실제 샘플 캡처의 글자와 이미지가 생성 시안의 가상 사이트와 다른 점은 의도한 차이다. 글로벌 검색과 기존 메뉴 항목은 기존 앱과 동일하게 유지한다.

## 모션

GSAP SplitText로 주요 제목 세 곳의 글자를 줄 마스크 안에서 순서대로 표시한다. autoSplit으로 폰트·줄바꿈 변경에 대응하고 aria:auto로 원문을 읽을 수 있게 유지한다. 제목/본문/이미지/항목/메모/보드에 ScrollTrigger 등장 효과를 적용하고 충분히 화면 밖으로 지난 뒤 돌아오면 재생한다. 이미지 마스크, 항목 stagger, 선택 이미지 전환, 보드 추가 효과를 구분한다. Rawdoc식 pinned 탭은 사용하지 않는다. 움직임 감소에서는 모든 내용을 즉시 표시한다. 페이지 이탈 때 SplitText·ScrollTrigger를 정리한다.
