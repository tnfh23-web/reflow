# REFLOW · 리플로우 — 디자인 콘셉트 v1

2026-10-11. 화면 흐름 정리 후 사용자가 다음 단계 판단을 위임했다. 다음 단계는 이미지 시안 제작으로 선택했다. 사용자의 C드라이브 폴더 요청에 따라 실제 프로젝트 경로는 `C:\Reflow`다. 기존 SIGNAL 파일은 수정·삭제하지 않는다.

## 목적과 핵심 경험

웹 제작자가 발견한 사이트를 저장하고, 시각·배치·실제로 관찰한 동작을 이해하며, 한국어 자연어 검색과 두 항목 비교로 다시 찾고, 프로젝트의 필요한 구간에 담아 활용하는 개인 서비스다. 홍보 랜딩·공개 피드·팀 협업·그래프 도구로 확장하지 않는다.

확정된 흐름은 `docs/screen-flow.md`를 따른다. 샘플 선택 복사, 비동기 작업, 수동 업로드 대안, 프로젝트 스냅샷 유지, 선택적 업데이트, 라이브러리 삭제 후 보드 자료 유지가 포함된다. 로그인·백엔드·캡처·AI는 실제 연결이 필요한 기능이며 이미지 시안에서 실행했다고 주장하지 않는다.

## 시각적 방향

콘셉트: 이미지가 주인공인 시각 레퍼런스 서재. 가벼운 앱 셸과 읽기 쉬운 조작 영역 안에서 다양한 웹 화면의 색·구도가 살아난다.

- Light 기본: 실제 흰색 #FFFFFF 캔버스, 사이드바 #F6F7F9, 본문 #191B20, 보조 글자 #6B707A, 경계 #E5E7EC. 코발트 #3454F4는 주요 저장 동작·선택·포커스에만 사용한다.
- Dark 대응: #15171B 캔버스, #1E2127 패널, #F3F4F6 글자. 이미지에 테마용 틴트를 덧씌우지 않는다. 밝은 시안 수락 뒤 동일 구조의 별도 상태 시안을 제작한다.
- 본문·UI Pretendard. 제목도 읽기 좋은 산세리프, 30~36px 중심. REFLOW 워드마크는 단단한 그로테스크 산세리프. 세리프·거대한 홍보 카피·장식용 영어 문구를 쓰지 않는다.
- 데스크톱 셸: 약 200~216px의 조용한 좌측 사이드바, 상단 공통 검색, 콘텐츠 여백 약 40~48px. 좁은 데스크톱에서 이미지 폭과 텍스트 가독성을 우선한다.
- 주요 구조: 이미지와 제목만 있는 Masonry 라이브러리 / 큰 이미지와 섹션 탐색 레일 / 두 항목 비교 / 정돈된 프로젝트 섹션 보드. 모든 영역을 카드나 둥근 컨테이너로 감싸지 않는다.
- 이미지 프레임 모서리는 약 6~8px, 작은 조작은 약 6px. 브라우저 창 테두리나 카드 그림자로 자료를 과도하게 둘러싸지 않는다.
- 최신 사용자 요구: UI 어디에도 화살표·chevron을 사용하지 않는다. 뒤로/이전/다음은 글자로 표시한다. '새 레퍼런스' 버튼 앞 기호도 제거해 글자만 둔다. 전후 이미지 사이 화살표나 드롭다운 화살표도 금지한다. 검색·닫기 등 화살표가 아닌 필요한 아이콘만 유지한다. 메뉴·설명은 한국어, 디자인 태그는 영어.

## 이번 시안 범위

1. `01-library-light.png`: 로그인 후 라이브러리. 최근 저장과 전체 항목의 이미지 탐색, Style/Layout/Interaction 필터, 공통 검색, 새 레퍼런스 진입.
2. `02-detail-analysis.png`: 상세의 분석 패널을 연 상태. 전체 캡처, 섹션 썸네일 탐색, 색상·레이아웃·관찰한 모션의 전후 이미지, 메모와 원본 방문·프로젝트 추가. 기본 패널은 닫힘이며 이 시안은 열린 상태다.
3. `03-compare.png`: 두 레퍼런스의 큰 이미지, 색상·레이아웃·인터랙션 비교. 검색 복귀 동작이 분명하다.
4. `04-project-board.png`: 프로젝트 이름·한 줄 설명, 순서 변경 가능한 섹션과 구간 자료, 디자인 방향 생성 버튼. 전체 라이브러리를 대신하는 자유 캔버스가 아니다.
5. `05-library-mobile.png`: 터치 환경의 라이브러리. 검색·탐색·저장·메모·프로젝트 추가를 살리고 hover 전용 조작을 피한다.

로그인, 저장 모달, 프리뷰, AI 방향 패널, 빈 상태·실패·한도 상태 및 Dark는 구현 전에 같은 시스템의 추가 상태 설계가 필요하다. 이번 다섯 화면이 모든 제품 상태를 끝낸 것으로 설명하지 않는다.

## 시안용 콘텐츠

시안의 사이트 화면은 구성·밀도·비교를 설명하는 생성 예시다. 실제 웹사이트를 캡처·분석한 결과가 아니다. 이름: FORM ARCHIVE, FIELD NOTES, PULSE STUDIO, FLOW DESK, FRAME ATELIER, MATERIAL INDEX. 실제 샘플 사이트 선정·권리·브라우저 캡처는 별도 단계에서 확인한다.

프로젝트 예시: '문화 공간 웹사이트', 설명 '이미지와 여백을 중심으로 전시와 프로그램을 소개합니다.' 섹션 예시: Hero, 콘텐츠, 인터랙션, Footer. 과금·사용자 수·수익·분석 정확도 등의 가짜 지표를 넣지 않는다.

## 구현과 검토 경계

- 이번 산출물은 Image Gen UI 이미지와 기획 문서다. 실행 가능한 앱·검증된 API·브라우저 렌더가 아니다.
- 실 구현에서는 UI 글자·검색·필터·폼·컨트롤을 React + Vite의 코드로 만든다. 시안을 배경 한 장으로 붙이지 않는다.
- 네 워크플로의 frontend-experience와 Build Web Apps frontend-app-builder의 콘셉트 우선 흐름을 적용했다. 커스텀 디자인 에이전트는 사용하지 않았다.
- 승인된 시안은 화면·색·타이포·자산·인터랙션 규칙으로 추출하고 실제 렌더와 비교한다. 이번 단계에서 기술·무료 할당량 품질 테스트를 했다고 주장하지 않는다.
- 비용은 먼저 결과를 확인하고 필요하면 유료 운영을 검토한다. 이번 단계에서 외부 계정 연결이나 유료 플랜 설정을 수행하지 않는다.
