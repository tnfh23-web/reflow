# REFLOW · 리플로우 — 화면별 사용 흐름

정리일: 2026-10-11 KST. 사용자 선택 A(화면별 사용 흐름 정리)에 따른 기획 문서. 구현·시안·실제 API 검증 결과가 아니다. 확정 사항은 사용자의 기획 결정에 근거하며, 새 연결 방식은 아래에서 '제안' 또는 '미정'으로 구분한다.

## 핵심 흐름

샘플 탐색 → 로그인 → URL 저장 → 비동기 캡처·분석 → 상세 확인·메모 → 검색·두 항목 비교 → 프로젝트에 필요한 구간 배치 → 디자인 방향 생성.

### 1. 첫 방문 / 라이브러리

- 홍보용 랜딩 대신 라이브러리가 첫 화면이다. 로그인 전에도 미리 준비한 샘플을 탐색한다.
- 샘플은 인터랙션 중심 웹사이트와 실제 서비스 UI를 함께 구성한다. 카드 기본 정보는 이미지·사이트명이며, 상세/프리뷰에서 정보를 확장한다.
- 자신의 레퍼런스를 저장하려면 로그인한다. 이메일+비밀번호와 Google 로그인 계획을 유지한다.
- 제안: 저장하다 로그인하게 되면 입력한 URL을 보존하고 완료 뒤 저장 흐름으로 복귀한다. 가입 때문에 같은 URL을 다시 입력하지 않게 한다.
- 확정 B: 로그인 후 원하는 샘플을 개인 라이브러리에 복사해 메모·수정·프로젝트 추가에 활용한다. 개인 수정은 샘플 원본이나 다른 사용자의 복사본에 영향을 주지 않는다. 가입 시 시작 컬렉션을 자동으로 추가하지 않는다.

### 2. 새 레퍼런스 저장 / 상세 진입

- 사이드바의 새 레퍼런스 → URL 하나를 입력하는 모달 → 기록을 먼저 저장하고 상세로 진입한다.
- 화면을 떠나도 서버에서 캡처·분석 작업을 계속한다. 완료/실패 알림은 toast로 제공한다. 별도 알림 센터나 라이브러리 상태 배지를 늘리지 않는다.
- 전체 데스크톱 페이지를 보관하고 섹션별 탐색을 제공한다. 모바일 캡처는 필요할 때 추가한다.
- 자동으로 스크롤·호버·메뉴·탭 열기를 관찰한다. 영상 보관 대신 실제 변화 전후 이미지와 종류·트리거·동작 설명을 제공한다. 관찰하지 못한 동작은 없다고 단정하지 않는다.
- 캡처 실패는 자동 재시도 1회, URL·제목·날짜 보존, 수동 재시도/이미지 업로드로 연결한다. 무료 캡처 한도 소진 시 URL을 보존하고 직접 이미지 업로드로 계속 사용한다.
- 업로드한 정적 이미지에서는 모션·CSS를 추측하지 않는다. 비주얼 분석과 사용자 입력을 지원한다.
- 중복 URL은 기존 항목 열기 또는 재캡처 업데이트 선택, 기존 메모 보존.
- 재캡처 시 기존 프로젝트에 담은 이미지·구간은 유지한다. 새 캡처를 확인한 뒤 사용자가 원하는 항목만 업데이트한다(B 확정). 라이브러리의 최신 캡처가 프로젝트 선택을 자동 교체하지 않는다.
- 제안: 준비 중 상세 이미지 영역에 작업 안내를 표시하고, 분석이 끝나기 전에도 메모·원본 방문을 사용할 수 있게 한다.

### 3. 레퍼런스 상세 / 프리뷰

- 프리뷰: 이미지·사이트명·URL·핵심 태그·프로젝트 추가. 방향키로 이전/다음, X·밖 클릭·Escape로 닫기. 원본 방문은 상세에서 제공한다.
- 상세: 큰 전체 캡처와 섹션 썸네일 탐색, 원본 방문, 저장 날짜, 개인 메모.
- 분석 패널은 우측, 기본 닫힘, 마지막 열림 상태 기억. 색상 HEX/역할, 실제 읽은 CSS 타이포 값, 레이아웃, 관찰한 인터랙션을 확인한다.
- 태그·분석 설명·섹션 이름을 수정할 수 있다. 섹션 삭제 및 직접 영역을 드래그해 새 구간을 만드는 기능을 제공한다.
- 수정값과 메모도 검색 대상이다. 수정으로 AI 모델을 학습시키는 기능은 아니다.
- 전체 사이트 또는 특정 구간을 프로젝트의 원하는 섹션에 추가할 수 있다.
- 라이브러리에서 레퍼런스를 제거해도 프로젝트에 담아둔 이미지·선택 구간은 유지한다(B 확정). 삭제 안내에서 적용 범위를 분명히 표현한다. 라이브러리에서 제거한 항목의 개인 메모 전체 보관을 자동으로 전제하지 않는다.

### 4. 다시 찾기 / 비교

- 라이브러리: 최근 저장 / 많이 본 항목 / 전체 항목. Style·Layout·Interaction 필터와 최신순·조회수순은 전체 영역에 적용한다.
- 상단 자연어 검색: 분석·수정값·메모를 검색하고 관련도·매칭 이유를 표시한다. 상세에서 관련 섹션을 확인한다.
- 두 레퍼런스를 선택해 큰 이미지와 색상·레이아웃·인터랙션 정보를 나란히 비교한다.
- 제안: 비교 선택 모드에서 두 항목을 고르게 하고, 비교를 닫으면 검색어·필터·탐색 위치를 보존한다. 기본 hover 동작인 프리뷰·프로젝트 추가를 복잡하게 만들지 않는다.

### 5. 프로젝트 보드 / 디자인 방향

- 프로젝트 이름+한 줄 설명 → AI 섹션 초안 → 섹션 추가/삭제/이름 수정/드래그 순서 변경.
- 사용자가 레퍼런스를 직접 선택하고 전체 사이트/특정 구간을 담는다. 같은 구간을 여러 프로젝트 섹션에 재사용할 수 있다. 추가순 기본, 드래그로 정렬한다.
- 프로젝트에 추가할 때 최근 프로젝트를 우선 보여주고 담을 섹션을 선택한다. 추가 이유 메모는 강제하지 않는다.
- 프로젝트 내 검색은 우측 패널로 보드를 유지하고, 결과 프리뷰·보드 위치 이동을 제공한다.
- 디자인 방향 생성은 명시적 버튼으로 실행한다. 색상·타이포·레이아웃·인터랙션의 구체적 적용 제안에 참고한 레퍼런스를 연결한다. 마지막 결과 저장·재생성, 기본 패널 숨김.
- 제안: AI 섹션 생성 실패 때 수동 구성으로 계속하고, 레퍼런스가 없는 보드에는 먼저 자료를 추가하도록 안내한다.
- 상태·마감일·진행률·보드 export·화면 시안 자동 생성은 현재 범위에 추가하지 않는다.

### 6. 모바일 / 설정

- 모바일은 검색·탐색·열람·URL 저장·메모·프로젝트 추가를 지원한다. 보드 섹션 편집·드래그 순서 변경은 데스크톱 중심이다.
- 제안: 모바일 비교는 두 이미지를 세로 배치해 읽을 수 있게 하고 데스크톱의 양쪽 폭을 억지로 축소하지 않는다.
- Settings는 계정+테마. 사이드바 Light/Dark 토글도 유지한다. 메뉴·설명은 한국어, 디자인 태그는 영어 용어다.
- 라이브러리 확대·비교·편집에는 풍부한 반응을 배치하고, 작업 중 강제 스크롤 고정은 피한다.

## 연결 과정의 추가 결정 — 모두 확정

1. 샘플 재사용 B: 원하는 샘플만 개인 라이브러리에 복사해 수정·메모·프로젝트 활용.
2. 재캡처 B: 프로젝트에 담은 모습은 유지하고 사용자 선택으로 최신 캡처로 교체.
3. 라이브러리 삭제 B: 라이브러리에서 제거해도 보드에 담은 이미지·구간은 유지.

화면 흐름에서 확인한 세 연결 사항의 토론을 완료했다. 상세 UI 제안과 실제 기술 동작은 구현·시안·검증 단계에서 확인해야 한다. 아직 구현 재개나 시안 생성을 선택하지 않았다.
